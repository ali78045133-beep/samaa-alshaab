# سماء الشعب - نظام إدارة البقالة

نظام متكامل لإدارة البقالة يعمل بالكامل بدون إنترنت، باستخدام React + Vite + Tailwind CSS + SQLite.

## المتطلبات

- Node.js 18+
- npm أو yarn

## التثبيت

```bash
# فك ضغط الملف
unzip samaa-al-shaab.zip
cd samaa-al-shaab

# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## البناء للإنتاج

```bash
npm run build
```

سيتم إنشاء المجلد `dist` جاهز للنشر على أي خادم ويب.

## الهيكل

```
src/
  components/     المكونات المشتركة
  pages/          صفحات التطبيق
  hooks/          Hooks مخصصة
  utils/          دوال مساعدة
  db.js           إدارة قاعدة البيانات
  App.jsx         التوجيه الرئيسي
  main.jsx        نقطة الدخول
```

## ملاحظات

- قاعدة البيانات تُحفظ في `localStorage` الخاص بالمتصفح.
- يُنصح بتصدير نسخة احتياطية بشكل دوري من صفحة الإعدادات.
- قارئ الباركود يتطلب السماح بالوصول للكاميرا.
